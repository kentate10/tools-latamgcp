# Lista semilla (solo nombres)

`squads_artefactos.csv` es unicamente una lista de nombres: artefacto, squad, IT element y como buscarlo. NO contiene vulnerabilidades, imagenes, versiones ni datos de Prisma.

La pestaña "Squad Beta" la usa como llave de busqueda: todo lo demas (donde corre, proyecto, namespace, ultimo tag, squads de CMDB) se consulta en vivo en GCP. Si un nombre cambia o se agrega un artefacto, edita este CSV y haz commit.
